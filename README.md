<h2>📋 Sobre o Projeto</h2>

<p>
O <strong>Controle de Estoque - Boteco do França</strong> foi desenvolvido para auxiliar no gerenciamento de produtos,
entradas e saídas de mercadorias, controle de usuários, acompanhamento de indicadores e geração de relatórios. Projeto realizado em Low/code
</p>

<p>
O sistema funciona totalmente no navegador utilizando <strong>LocalStorage</strong>,
dispensando banco de dados ou servidor para armazenamento dos dados.
</p>

<hr>

<h2>✨ Funcionalidades</h2>

<ul>
  <li>🔐 Sistema de Login</li>
  <li>👥 Controle de usuários e permissões</li>
  <li>📦 Cadastro de produtos</li>
  <li>📈 Dashboard com indicadores</li>
  <li>📊 Relatórios gerenciais</li>
  <li>📥 Registro de entradas</li>
  <li>📤 Registro de saídas</li>
  <li>⚠️ Alertas de estoque baixo</li>
  <li>📅 Controle de validade por lote</li>
  <li>💰 Controle de custos e PVP</li>
  <li>💾 Backup e restauração de dados</li>
  <li>📄 Exportação CSV</li>
</ul>
